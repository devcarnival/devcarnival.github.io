Modern applications generate enormous amounts of telemetry, but not every log tells a meaningful security story. Effective threat detection begins much earlier than the Security Operations Center (SOC) — it starts with how applications are designed, developed, deployed, and instrumented.

This session explores how developers, DevOps engineers, and security teams can work together to build security-aware applications that produce actionable, high-quality logs for SIEM platforms. From secure application logging and DevSecOps practices to log pipelines and SIEM detection engineering, the session demonstrates how to transform application events into meaningful security signals, detect suspicious behaviours, and accelerate incident response.

The core message: *Don't just build applications that work. Build applications that help security teams understand when something goes wrong.*

### Key Takeaways
- **Design security-aware logging:** Identify which application events matter for security, including authentication failures, privilege changes, suspicious API activity, and sensitive data access.
- **Build better telemetry:** Use structured logging, consistent schemas, timestamps, correlation IDs, and meaningful event context.
- **Integrate security into DevOps:** Embed security logging requirements into CI/CD pipelines, DevSecOps workflows, and application design.
- **Think like a detection engineer:** Translate application events into SIEM detection use cases, correlation rules, behavioural analytics, and alerts.
- **Improve signal quality:** Reduce noisy logs, false positives, missing context, and unnecessary ingestion costs.
- **Enable faster incident response:** Connect application logs with identity, endpoint, network, and cloud telemetry for better investigation and threat hunting.
- **Log responsibly:** Protect secrets, credentials, tokens, and sensitive personal data through appropriate data minimisation and access controls.

### Target Audience
- **Software Developers & Application Architects:** Developers, backend engineers, API developers, and architects who want to build observable and security-aware applications.
- **DevOps, SRE & DevSecOps Engineers:** Professionals responsible for CI/CD, cloud-native workloads, application observability, and secure deployments.
- **SOC Analysts & SIEM Detection Engineers:** Security professionals working on log onboarding, SIEM use cases, threat hunting, alert tuning, and incident investigation.
- **Students & Early-Career Professionals:** Students and aspiring professionals in software engineering, cloud computing, cybersecurity, and security operations.

*Recommended audience level: Beginner to intermediate, with practical examples accessible to developers and security practitioners.*
