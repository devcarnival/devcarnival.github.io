Manukumar V S is a Principal Quality Engineer in Oracle's Java Platform Group (JPG), where he has worked for more than seven years, and an OpenJDK JDK Committer. His experience within JPG gives him a close perspective on the evolution of the Java platform and the engineering decisions behind its long-term relevance. His interests include Java internals, the Vector API, hardware-aware performance, and AI-assisted software engineering. He actively experiments with the latest advances in AI, including coding agents and their practical use in software development.

At JavaOne 2022, he presented "Java and the Big Data World". He has also presented on the Vector API at Java user groups, conferences, and JavaFest, and on post-quantum cryptography at a Java user group. He enjoys making complex platform concepts approachable through practical examples and engineering trade-offs.
