Code On JVM Chennai is a premier developer community and collective of engineering excellence in Chennai, dedicated to uniting Java, Kotlin, and JVM enthusiasts to connect, learn, and build high-scale software systems.

### About Code On JVM Chennai

Operating in the heart of Chennai, Code On JVM Chennai bridges the gap between theoretical computer science and production-grade, enterprise-scale engineering. The community provides an open, collaborative platform where software engineers, distributed systems architects, open-source contributors, and aspiring developers converge to exchange real-world insights, unpack JVM internals, and explore cutting-edge backend technologies.

Through regular meetups, hands-on coding labs, hackathons, and architecture discussions hosted at leading educational institutions and technology hubs across Chennai, Code On JVM fosters an inclusive environment that champions deep technical rigor and active engineering craftsmanship.

### Core Focus Areas

- **JVM Internals & Runtime Performance:** Profiling, memory tuning, JIT compilation, bytecode analysis, and modern garbage collectors (ZGC, Shenandoah, G1GC).
- **Modern Java & Kotlin Ecosystems:** Modern Java evolutions (Virtual Threads, Project Loom, Pattern Matching), alongside Kotlin-based microservices and asynchronous programming.
- **Enterprise Architecture & Production Engineering:** Distributed architectures, high-throughput backend services, event-driven pipelines, and Spring Boot / Quarkus ecosystems.
- **Data Structures in Production:** Deep-dive studies into production-grade structures including Bloom Filters, Log-Structured Merge-trees (LSM-trees), and vector indexing.
- **Mentorship & Community Enablement:** Bridging academia and industry through practical workshops, open-source collaboration, and developer networking.

### DevCarnival 2026 Collaboration

As an ecosystem community partner for DevCarnival 2026, Code On JVM Chennai collaborates to empower developers with high-scale enterprise engineering insights, hands-on JVM masterclasses, and vibrant community-driven learning tracks.
