Tamilnadu Java User Group (TNJUG) is a grassroots community uniting enterprise software engineers, university professors, campus chapters, and student programmers to advance modern Java, Spring Boot, cloud architecture, and open source across Tamil Nadu.

### About Tamilnadu Java User Group

Operating at the intersection of industry engineering and higher education, Tamilnadu Java User Group bridges the gap between academic curricula and production-grade enterprise software development. The community fosters an open, collaborative ecosystem where seasoned architects, faculty champions, and aspiring developers connect to share knowledge, run hands-on labs, and co-build open-source software.

Through regular statewide technical meetups, deep-dive workshops, and collegiate campus initiatives, TNJUG empowers technologists across Tamil Nadu to stay at the cutting edge of JVM innovations and distributed systems engineering.

### Core Focus Domains

- **Modern Java & JVM Internals:** In-depth explorations of modern Java language features (Java 21/25+), Virtual Threads (Project Loom), concurrency models, garbage collection ergonomics, and JVM performance tuning.
- **Enterprise Spring Ecosystem:** Architecture and engineering best practices using Spring Boot 3+, Spring Security, Spring Cloud microservices, and reactive APIs with Project Reactor.
- **AI on the JVM & Spring AI:** Building production-ready intelligent applications on the JVM using Spring AI, vector database integrations, Retrieval-Augmented Generation (RAG), and enterprise LLM orchestration.
- **Cloud-Native & Distributed Architectures:** Microservices design, containerization with Docker and Kubernetes, GraalVM native image compilation, distributed tracing, and event-driven architectures.
- **Open Source Engineering & Tooling:** Production testing, CI/CD automation, build systems (Maven/Gradle), code quality practices, and contributing to global open-source ecosystems.

### Flagship Initiatives & Programs

- **Collegiate Campus Chapters:** A dedicated network of collegiate chapters pairing faculty mentors, student organizers, and industry tech leads to deliver structured, hands-on learning labs. Active chapters include:
  - **Kongu Engineering College (Erode):** Hands-on labs focusing on Java EE, Spring Security, and cloud computing.
  - **PSNA College of Engineering and Technology (Dindigul):** Enterprise Java excellence, microservices, and open-source collaboration.
  - **Sri Eshwar College of Engineering (Coimbatore):** Spring Boot study circles, architecture workshops, and student hackathons.
  - **VET Institute of Arts and Science (Erode):** Student developer innovation, foundational coding mastery, and coding club enablement.
- **Open Source Labs:** A dedicated practical initiative where student builders work directly on real-world open-source software and tools under the mentorship of senior industry engineers.
- **Technical Meetups & Conferences:** Statewide technical meetups, community teardowns, and regional events connecting developers across Coimbatore, Madurai, Erode, Dindigul, and Chennai.
- **Faculty Enablement & Academic Alliances:** Partnering with academic leaders and university professors to modernize engineering pedagogy, run faculty hackathons, and align coursework with industry needs.

### DevCarnival Collaboration

As an ecosystem partner for DevCarnival 2026, Tamilnadu Java User Group collaborates to deliver deep-dive sessions on modern JVM architectures, Spring AI, and high-scale enterprise engineering, while spotlighting standout student-led projects and open-source innovations at the Tech Pavilion.
