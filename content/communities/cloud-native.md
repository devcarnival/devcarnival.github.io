Cloud Native Chennai is an official Cloud Native Community Group (CNCG) affiliated with the Cloud Native Computing Foundation (CNCF). Active since 2020, the community brings together cloud architects, software engineers, DevOps practitioners, researchers, and students across Chennai to learn, collaborate, and build modern scalable systems using open-source, vendor-neutral cloud-native technologies.

### Technical Domains Handled

The community organizes in-depth discussions, architecture reviews, and hands-on workshops across key cloud-native disciplines:

- **Containers & Orchestration**: Kubernetes (K8s) architecture, multi-cluster management, declarative deployment strategies, and runtime internals (containerd, CRI-O).
- **GitOps & Continuous Delivery**: Declarative infrastructure management, automated deployments, and progressive delivery using Argo CD, Flux, and Flagger.
- **Service Mesh & Cloud Networking**: Microservices traffic management, dynamic routing, mutual TLS (mTLS), and zero-trust connectivity with Istio, Envoy, and Linkerd.
- **eBPF & Distributed Observability**: Modern kernel-level observability, high-performance network filtering, distributed tracing, and metrics collection using OpenTelemetry, Prometheus, Grafana, and Cilium.
- **Cloud-Native Security & Policy Engine**: Container security, vulnerability scanning, policy-as-code with Kyverno, zero-trust infrastructure access via Teleport, and secret management with HashiCorp Vault.
- **Platform Engineering**: Building Internal Developer Platforms (IDPs), developer self-service workflows, and infrastructure composition with Crossplane and Terraform.
- **Cloud Native AI & Data Workloads**: Orchestrating distributed machine learning pipelines, LLM model serving, and dynamic auto-scaling on Kubernetes using KubeFlow, Ray, and KEDA.

### Flagship Initiatives & Community Activities

- **Monthly Technical Meetups**: Regular in-person meetups hosted across leading tech hubs and development centers in Chennai, featuring architectural case studies and deep-dive technical talks.
- **Kubernetes Community Days (KCD) Chennai**: Flagship community conference supported by the CNCF, bringing together hundreds of cloud practitioners, international speakers, and open-source maintainers.
- **Hands-on Labs & Architecture Workshops**: Interactive sessions designed to help engineers transition from container fundamentals to production-grade, enterprise-scale Kubernetes deployments.
- **Open-Source Knowledge Sharing**: Slide decks, sample manifest repositories, and demo code maintained and freely shared on the community's [GitHub Organization](https://github.com/CNChennai).

### DevCarnival Collaboration

As an active ecosystem partner for DevCarnival, Cloud Native Chennai drives hands-on workshops, cloud architecture tracks, and interactive Tech Pavilion showcases—demonstrating real-world cloud-native engineering and mentoring the next generation of cloud developers.
